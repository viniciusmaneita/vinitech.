# ViniTech — Informática e soluções digitais

Site de apresentação dos serviços de Vinicius Maneita, com layout responsivo e contato por WhatsApp.

## Arquivos

- `index.html`: página principal e textos.
- `assets/css/style.css`: cores, layout e adaptação ao celular.
- `assets/js/script.js`: mensagens do WhatsApp e seleção do serviço.

## Como enviar ao GitHub

1. Extraia o arquivo ZIP no seu computador.
2. Crie um repositório chamado `vinitech` no GitHub.
3. Dentro dele, escolha **Add file → Upload files**.
4. Arraste o arquivo `index.html`, o arquivo `README.md` e a pasta `assets` juntos para a área de envio.
5. Clique em **Commit changes** para salvar.

Envie o conteúdo extraído, não o ZIP. O arquivo `index.html` deve aparecer diretamente na página principal do repositório, ao lado da pasta `assets`.

## Como visualizar antes de publicar

Abra o arquivo `index.html` no navegador. Mantenha a pasta `assets` ao lado dele.

## Publicação pelo Cloudflare Pages com GitHub

Depois de enviar os arquivos ao GitHub, conecte esse repositório ao Cloudflare Pages. Este é um site HTML estático: não precisa de instalação ou comando de compilação. Selecione a pasta principal do projeto como diretório dos arquivos publicados. Os nomes dos campos podem variar no painel.

## Personalização

Edite os textos em `index.html`, o visual em `assets/css/style.css` e as mensagens em `assets/js/script.js`. Não há cadastro, banco de dados ou formulário que armazene informações.

## Atualização com foto

A foto está em `assets/img/vinicius.jpg`. O enquadramento é feito pelo CSS; a imagem original foi preservada.

Para atualizar o repositório existente: extraia o ZIP, escolha Add file → Upload files e envie index.html, README.md e a pasta assets juntos. Confirme a substituição dos arquivos existentes em Commit changes. Não crie uma pasta extra no repositório.
